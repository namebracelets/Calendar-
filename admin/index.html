You only do this once per device. Your token is encrypted with your admin password and stays in this browser. It is never put on the public website.

How do I get a token?
  1. On GitHub (signed in), open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: Calendar admin. Expiration: the longest option offered.
  3. Repository access: Only select repositories → pick your calendar repository.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else as is.
  5. Click Generate token, copy it, and paste it above.
